Programador do rádio via navegador (Web Serial) — Uniden BC75XLT / UBC75XLT

Desconectado
⚠️ Seu navegador não suporta a Web Serial API. Use Google Chrome ou Microsoft Edge em uma página HTTPS (GitHub Pages fornece HTTPS automaticamente).
ℹ️ Como usar
  1. Conecte o rádio ao computador pelo cabo USB (driver CP210x instalado).
  2. Clique em Conectar rádio e escolha a porta serial na janela do navegador.
  3. Use Ler do rádio para carregar tudo do rádio, ou Importar arquivo para carregar um .bc75xlt_ss.
  4. Edite as frequências nas abas de banco e as configurações no painel.
  5. Use Gravar no rádio para enviar ao rádio (marque "limpar antes" para apagar tudo primeiro).
  6. Use Salvar arquivo para baixar um arquivo .bc75xlt_ss compatível com o software original.
