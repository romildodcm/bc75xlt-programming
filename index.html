    help Como usar

    1. Conecte o rádio ao computador pelo cabo USB (driver CP210x instalado).
    2. Clique em Conectar rádio e escolha a porta serial na janela do navegador.
    3. Use o botão Ler do rádio (ícone de download, no topo) para carregar tudo do rádio, ou Importar arquivo para carregar um .bc75xlt_ss.
    4. Edite as frequências nas abas de banco e as configurações na aba Configurações.
    5. Use o botão Gravar no rádio (ícone de upload, no topo) para enviar ao rádio — um modal vai perguntar se você quer limpar a memória antes.
    6. Use Salvar arquivo para baixar um arquivo .bc75xlt_ss compatível com o software original.

    A comunicação é feita direto pelo navegador (Web Serial API) — nenhum dado sai do seu computador. Requer Chrome ou Edge em uma página HTTPS.
